## EvoDiff: biophysical supervision (November 2026)

The EvoDiff experiments since Check-in 1 are documented in [the EvoDiff research update](docs/evodiff/README.md): the METL-Global dataset, Rosetta target-group comparisons, evaluation on two other proteins, and the tests of less-aggressive fine-tuning. The results are mixed. We have not run the ProteinGym experimental evaluation yet. The [methods](docs/evodiff/methods.md), [figures](docs/evodiff/figures.md), [limitations](docs/evodiff/results.md), and [AI-use note](docs/evodiff/ai_use.md) are kept with the code. The fine-tuning and plotting scripts were developed with help from published libraries and ChatGPT, as disclosed there.
