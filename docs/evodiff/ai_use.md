Use of AI and external code

I had to consult the published libraries and AI, ChatGPT in particular, for fine-tuning scripts and plot generation.

I used ChatGPT extensively while writing and debugging the Python training scripts, Slurm jobs, evaluation code, and plotting scripts. I also used it to help organize and draft the documentation in this repository. The EvoDiff and METL implementations, published papers, and library documentation were other references. I don't want to present this code or these notes as work I produced entirely without assistance.

I ran the experiments on Engaging and reviewed the reported results. That doesn't replace checking the code itself. In particular, the extra 500 development labels in the target-protein support experiments and the limitations of the masked-token evaluation are documented because they affect how we should interpret the numbers.

This note covers the EvoDiff experiments and documentation included here.
